# Getting help with TraceBrain

- **Something is broken:** open an issue with the bug report form. Include what you ran, what you
  expected and what happened.
- **An idea or a missing feature:** open an issue with the feature request form.
- **A security problem:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

This project is maintained in the open by [@boss477](https://github.com/boss477). Answers are best
effort.
